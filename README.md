# Student Management System

A full-stack Student Management System built using **React.js, Vite, Node.js, Express.js, and MySQL**.

The application allows users to manage student records through a web interface. The frontend communicates with the backend through REST APIs, while MySQL is used for persistent data storage.


*** important this project need node and mysql.***

---

## 🚀 Tech Stack

### Frontend

- React.js
- Vite
- React Router
- Axios
- CSS

### Backend

- Node.js
- Express.js
- MySQL2
- CORS
- dotenv
- Nodemon

### Database

- MySQL 8.4
- Database: `student_db`
- Table: `students`
